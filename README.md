# Bihe Concierge ✦

A premium, private matchmaking and relationship concierge service application. 

Unlike generic dating platforms, Bihe Concierge is designed to feel like a carefully curated editorial magazine, a premium wedding invitation, and a ceremonial journey. The interface prioritizes emotional resonance, privacy, refinement, and sophisticated Nepali cultural storytelling.

## 🏛️ Architecture & Tech Stack

This project is built using a lightweight, dependency-free frontend stack to ensure maximum performance, smooth animations, and total control over the DOM.

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom variables, responsive design, and luxury animations (no Tailwind/Bootstrap).
- **Vanilla JavaScript (ES6)**: Modular architecture without frameworks (no React/Vue/Angular).

## ✨ Key Features

- **Multi-Stage Application Journey**: 6 distinct stages seamlessly transitioning without page reloads.
- **Compatibility Blueprint**: A customized 10-question interactive assessment engine.
- **Strict Client-Side Validation**: Ensures only legitimate, properly formatted information is submitted.
- **Cinematic Animations**: Uses `requestAnimationFrame` and custom CSS easing for smooth, editorial-style reveals.
- **State Persistence**: Auto-saves application progress using `sessionStorage` and `localStorage`.

## 🎨 Design Language

- **Typography**: Cormorant Garamond, Playfair Display, and Inter.
- **Palette**: Warm ivory, cream, cinematic black, and deep burgundy (wine).
- **Vibe**: Emotional, private, refined, and expensive.

## 🚀 Setup & Deployment

Since this is a static frontend application, it can be served using any basic HTTP server.

```bash
# Clone the repository
git clone https://github.com/khadka-sumit/bihe-concierge.git

# Navigate to the project directory
cd bihe-concierge

# Serve locally (using Python for example)
python -m http.server 8000
```
